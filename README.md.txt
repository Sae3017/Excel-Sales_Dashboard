Excel Sales Dashboard Project

Project Overview

This project analyzes retail sales data using Microsoft Excel. The goal is to understand sales performance, compare products and regions, and present meaningful business insights through a dashboard.

Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Excel formulas
- Data cleaning
- Interactive dashboard

Project Objectives

- Calculate total sales.
- Identify top-performing products.
- Compare sales across different regions.
- Analyze order quantities.
- Present key business insights to support decision-making.

Excel Skills Demonstrated

- Data cleaning and formatting
- SUMIF and COUNTIF functions
- IF functions
- PivotTables and PivotCharts
- Dashboard creation
- Business insights and reporting

Project Files

- "Sales_Dashboard_Project.xlsx" — Excel workbook containing the sales data, analysis, and dashboard.

Outcome

This project demonstrates how Microsoft Excel can transform raw retail sales data into meaningful business insights to support better decision-making.
